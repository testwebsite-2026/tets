📊 Financial Data Extractor

Upload a source document (receipt / invoice / report) and a target template, and get a clean Markdown table mapped to your template's columns.

1 Free API Key

This app uses Google's Gemini API, which has a free tier — no credit card required. Get a free key at aistudio.google.com/apikey (sign in with any Google account, click "Create API key"). Your key is used only in your browser to call Gemini directly — it is never sent anywhere else and is not stored unless you check "remember".
